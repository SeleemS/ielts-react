  <p>Matching Features is one of the trickiest question types in IELTS Reading, and one candidates rarely practise in isolation. You are given a list of statements and a separate box of options — often researchers, theories, countries, time periods, or categories labelled with letters — and you must decide which option each statement belongs to. A typical instruction reads: <em>"Match each statement with the correct researcher, A-E. Write the correct letter in boxes 1-6. NB You may use any letter more than once."</em> That last line changes everything, and skimming past it costs marks.</p>

  <h2>What Matching Features actually tests</h2>
  <p>Unlike question types that reward reading for the main idea, Matching Features tests whether you can attach a <strong>specific detail to its correct source</strong>. The passage usually reports what several different people, studies, or places said or did, and the statements scramble those attributions. Your job is to untangle who claimed what. Because the options are fixed and reusable, the type behaves less like reading and more like careful cross-referencing.</p>
  <p>Reading has 40 questions and 60 minutes across three passages, with no extra transfer time, so an inefficient method here drains the clock you need for the rest of the paper. The good news is that Matching Features rewards a repeatable routine more than raw reading speed.</p>

  <h2>The two rules that catch people out</h2>
  <ul>
    <li><strong>The answers are not in passage order.</strong> Unlike <a href="/reading/true-false-not-given">True/False/Not Given</a> or sentence completion, which march down the text, a Matching Features set can send you from the last paragraph back to the first. Do not expect statement 2 to sit below statement 1 in the passage.</li>
    <li><strong>Options may repeat — or never appear.</strong> Read the instruction. If it says you may use a letter more than once, one researcher might answer three statements while another answers none. Never cross an option off just because you have already used it, and never assume every option must be used.</li>
  </ul>

  <h2>Do the options, not the statements, first</h2>
  <p>The efficient approach flips the usual order. Instead of taking each statement and hunting the whole passage for it, anchor yourself on the <strong>options box</strong>, because the names or categories in it are almost always easy to find in the text — they are usually capitalised or clearly signposted.</p>
  <ol>
    <li><strong>Skim the passage once and mark where each option appears.</strong> Put a small letter in the margin next to every place a researcher, study, or category is named. Some options are discussed in one place; others are scattered.</li>
    <li><strong>Read each statement and underline its concrete idea</strong> — the claim, finding, or characteristic being attributed. Ignore filler like "argues that" and focus on <em>what</em> is argued.</li>
    <li><strong>Go to the marked locations for the relevant option and read carefully.</strong> Because you already know where each name lives, you are reading two or three sentences, not the whole passage.</li>
    <li><strong>Match on meaning, not matching words.</strong> The statement will paraphrase the text. If the passage says a researcher "found no measurable benefit," the statement may read "was unconvinced by the results."</li>
  </ol>

  <h2>A worked example</h2>
  <p><strong>Options:</strong> A. Dr. Chen &nbsp; B. Professor Adams &nbsp; C. Dr. Okonkwo</p>
  <p><strong>Statement:</strong> "believed the original data had been collected too hastily to be reliable."</p>
  <p><strong>Passage extract:</strong> "Adams accepted the broad conclusion, but Okonkwo was more cautious, noting that the survey had been rushed through in a single season and might therefore misrepresent long-term patterns."</p>
  <p>The answer is <strong>C</strong>. The passage never uses "hastily" or "reliable"; it uses "rushed through" and "might misrepresent." Adams is mentioned in the same sentence, which is exactly the trap — proximity is not attribution. Read to the end of the thought and confirm <em>whose</em> view it is before you write a letter.</p>

  <h2>How Matching Features differs from its neighbours</h2>
  <p>Candidates often muddle this type with two others, and the confusion wastes time:</p>
  <ul>
    <li><strong>Versus <a href="/reading/matching-headings">Matching Headings</a>:</strong> Matching Headings wants the main idea of a whole paragraph. Matching Features wants a specific detail attached to a specific source. One is about gist; the other is about precision.</li>
    <li><strong>Versus <a href="/blog/ielts-reading-matching-information">Matching Information</a>:</strong> Matching Information asks which paragraph contains a detail. Matching Features asks which person or category a detail belongs to. The difference is <em>where</em> versus <em>who</em>.</li>
  </ul>

  <h2>Traps that quietly cost marks</h2>
  <ul>
    <li><strong>Matching by proximity.</strong> Two names often sit in one sentence. The claim belongs to only one of them, so read the connecting words — <em>but</em>, <em>whereas</em>, <em>by contrast</em> — that separate their views.</li>
    <li><strong>Assuming one option per statement.</strong> If letters can repeat, treat each statement independently and let the same letter answer several.</li>
    <li><strong>Getting stuck.</strong> If a statement resists after about 90 seconds, leave it. Once the clearer ones are placed, elimination narrows what remains.</li>
    <li><strong>Ignoring the "not used" possibility.</strong> An option with no matching statement is normal, not a sign you made a mistake.</li>
    <li><strong>Leaving blanks.</strong> There is no penalty for a wrong answer, so every box should have a letter before the hour ends.</li>
  </ul>
